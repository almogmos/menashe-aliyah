# לוח העלייה, מבצע כנפי שחר

דף אחד לצוות העלייה של פרויקט בני מנשה, נובמבר 2026, מ-11.11 ועד הטיסה האחרונה ב-26.11.
ארבעה אזורים: עמוד ראשי, לוח זמנים, עולים (כולל טבלת השליטה) וטקסים.

## מה יש בדף ומה אין

- הכל נלקח ממערכת הניהול המלאה של הפרויקט, רק החלק של העלייה מ-11.11.
- ראיונות, תקציב ומסמכים לא נכנסים לדף.
- העולים מופיעים רק כמספרים: אין שמות, תאריכי לידה, דרכונים, מספרי תיקים או הערות חופשיות.
  הספירות נעשות בסקריפט, ורק הן נשמרות ב-`data.json` וב-`index.html`.
- מספרי הזמנה של כרטיסים מוסרים מההערות.

## איך הדף מתעדכן

משימה מתוזמנת שולפת את הנתונים מהמערכת המלאה, מריצה את הסקריפט ומעלה גרסה חדשה רק כשמשהו השתנה.

```
python3 scripts/build.py <תיקיית הנתונים>
```

תיקיית הנתונים כוללת את המסמכים מהמערכת המלאה: `gantt/main.json`, `welcomes/main.json`, `visa/main.json`
ו-`ticketing/{meta,assign,p1..p6}.json`. היא לעולם לא נכנסת לריפו (ראו `.gitignore`).

## קבצים

- `index.html`: הדף עצמו, עם הנתונים בפנים.
- `data.json`: אותם נתונים, לצורך בדיקה ומעקב שינויים.
- `scripts/build.py`: בונה את שני הקבצים מהמערכת המלאה.
- `scripts/template.html`: העיצוב והקוד של הדף.
- `scripts/assets.html`: הלוגואים.
